# Task records

Tasks record implementation scope before changes. Each record identifies ownership, affected interfaces, dependencies, acceptance tests, actual validation evidence, and remaining gates. `TASKS.md` indexes progress; a completed source edit is not a completed product milestone.

Keep command results in `docs/testing.md` or a linked task record. Missing database, native device, browser, signing, or production evidence remains pending. All engineering rules live in the root `AGENTS.md` and byte-identical `CLAUDE.md`.
