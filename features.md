| Production supervisor   | Assigned production and readiness                     | No implicit engineering/QC approval                         |

| Quality inspector       | Inspection evidence                                   | Cannot independently release own evidence                   |
| Quality reviewer        | Hold/review/release                                   | Actor separation remains enforced                           |
| Subcontract coordinator | Vendor custody/reconciliation                         | No vendor-stock deletion or QC bypass                       |
| Packing/Dispatch        | Packages/scans/shipment                               | Current stock/QC/order gates apply                          |

| Auditor                 | Scoped readable history                               | No business mutations                                       |

The actual permission-key source is `packages/contracts/src/permissions.ts`, seeded into protected company mappings. Current database membership and plant scopes enforce each command. Multi-role assignment does not remove independent-review policy. Explicit grants cannot convey ownership actions.

## Desktop/backend continuation checkpoint

The reusable account security component permits MFA enrollment/verification independently of company administration access. Verified transfer recipients can accept their addressed ownership transfer without first requiring member-administration privileges. Plant options and explicit grants are validated and server-scoped.

Pending request recovery survives restart and preserves the exact key. Desktop acceptance also checks renderer Node isolation, forged sender rejection, encrypted snapshot export/decryption, and no duplicate commit after a simulated lost response. Team commands are blocked when offline. Item unit/grade/finish cannot change once referenced; NCR containment cannot be moved to a different lot or closed through text claims.

Production material consumption/output, NCR completion and CSV export remain disabled with reasons. Their complete approved engineering, reconciliation, review, or export-audit workflows remain backlog. Local WIP issue/return and vendor return/loss use real custody balances; this does not establish full M6/M7 acceptance. See docs/testing.md for exact executed counts and release limitations.

Stores workflow evidence includes minimal scoped sales/PO references, real partial PO receipt, remaining-obligation rejection and commercial-field minimization. Those projections supply operational selectors without granting sales.read or procurement.manage. The PostgreSQL suite now contains 58 executed assertions.

Entered receipt supplier references are retained in immutable audit evidence. Normalized receipt headers/certificates remain pending. Optional theme storage can fail without preventing startup; the business request journal still blocks dispatch if durable storage is denied.

Manual encrypted exports resolve directory aliases, flush an adjacent temporary ciphertext file, and replace only after the write completes. A real filesystem test preserves the previous file after simulated partial-write and replacement failures and verifies cleanup. Backup scheduling/retention and full restore activation remain pending.
